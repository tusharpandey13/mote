MOTE

Your Android phone, as a Bluetooth remote for your Mac.

Media keys, a D-pad, a touchpad mouse and a full keyboard in one hand. Mote pairs as an ordinary Bluetooth keyboard and mouse, so there is nothing to install on the computer.

Download the APK Try the demo

Android 9 or later, with Bluetooth. Works with macOS, Windows, Linux, iPadOS and smart TVs.

Use it from the browser

The web remote needs the Mote Helper on your Mac. A web page can't pretend to be a Bluetooth keyboard, so the helper receives your presses and performs them.

curl -fsSL https://tusharpandey13.github.io/mote/install.sh | bash

Run it in Terminal on your Mac. It downloads the helper from GitHub Releases into ~/Applications, opens it, and asks for Accessibility permission so it can press keys for you. Read the script first.

Over Wi-Fi

Open the address shown in the helper's menu bar, such as http://your-mac.local:8790, in any phone browser on the same network.

Over Bluetooth

Open tusharpandey13.github.io/mote/remote/ in Chrome on Android and pick your Mac. This uses Web Bluetooth, so no Wi-Fi is needed.

Four modes on one rail, under your thumb

  • Media and brightness

    Play, pause, skip, volume, mute and screen brightness, laid out to be found by feel in a dark room.

  • D-pad and scroll lever

    Arrow keys with OK and esc for slides and menus. Push the spring-loaded lever further to scroll faster.

  • Touchpad mouse

    Drag to move, tap to click, two fingers to scroll, long-press to right-click. Drag lock for selecting text.

  • Full keyboard

    A laptop-style deck with function keys, arrows and sticky modifiers: tap command once for one shortcut, twice to lock it.

  • Spaces tile

    Hold and slide to move between desktops one step at a time. Tap it for Mission Control.

  • Macros

    Shortcuts, typed text, sequences and click-at-point. Star the ones you use most and they appear on the Media screen.

It shows up as a keyboard and mouse

PhoneBluetooth HIDMac or PC

Standard Bluetooth HID. Android 9 added a way for apps to act as a Bluetooth keyboard and mouse. Mote uses it, so your computer sees the same kind of device as any wireless keyboard.

No software on the computer. No helper app, no accessibility permission, no Wi-Fi. Pair once from the computer's Bluetooth settings and it reconnects by itself.

Works before you log in. Because the operating system handles HID input directly, Mote can type your password at the login window and the lock screen. It isn't reliable at the FileVault prompt before startup, so keep a real keyboard nearby for that.

Install and pair

  1. Download the APK on your phone

    Open the latest release and tap the .apk file under Assets.

  2. Allow installs from your browser

    Android asks for permission the first time. Go to Settings, then Apps, then Special app access, then Install unknown apps, and turn it on for the browser you used. You can turn it off again afterwards.

  3. Open Mote and make the phone visible

    Tap the device pill, then Pair new device. Grant the Bluetooth permission. The phone stays discoverable for a couple of minutes.

  4. Pair from the computer

    On a Mac, open System Settings, then Bluetooth, and click Connect next to your phone. Confirm the same code on both screens. On Windows, use Settings, then Bluetooth & devices, then Add device.

  5. Press a key on your first Mac connection

    macOS may open Keyboard Setup Assistant to identify the keyboard type. Follow it once, or close it if you use a US layout.

Limits worth knowing

Mote only sends what a standard Bluetooth keyboard and mouse can send. That sets a few hard edges.

Why is the fn key greyed out?

Apple's fn (Globe) key is a private Apple signal, not a standard HID key, so no third-party keyboard can send it. Mote gives you a real F1 to F12 row instead, and shortcuts that need fn have to be remapped to another key.

I don't use a US keyboard layout. Will typing work?

Bluetooth keyboards send key positions, not letters. The computer turns positions into characters using its own input source. Shortcuts like command-C always land on the right key. For typed text and macros, set the computer's layout to match, or expect AZERTY, QWERTZ and Dvorak characters to come out shifted. Emoji and accented characters can't be typed directly.

Does the touchpad support Mac trackpad gestures?

No. Apple's multi-touch trackpad protocol is proprietary, so Mote is a mouse to the computer. Mote reads your fingers on the phone and turns them into mouse moves, clicks and scroll-wheel events. For switching Spaces and opening Mission Control, use the Spaces tile.

Do the brightness keys work?

Mote sends the standard display-brightness keys. Most Macs accept them for the built-in display. External monitors and some other hosts ignore them. Nothing on the phone can confirm the change, so check the screen.

Can I use Mote from this website?

Only with the Mote Helper on a Mac. Browsers can connect to Bluetooth devices but can't act as one, so a web page can't be a keyboard by itself. The helper takes its place. The demo shows the interface only and sends nothing.

Which phones work?

Android 9 or later with the Bluetooth HID device profile enabled. Most phones have it, but a few manufacturers have shipped it disabled or unreliable. If pairing never completes, that is the likely cause.
